About This Project

The EAS Weather Alert System is a comprehensive solution for generating and managing Emergency Alert System (EAS) notifications for severe weather events across the United States. Built with Python, it provides real-time alert generation, severity classification, and multi-state coverage.

This system is designed to help meteorologists, emergency managers, and weather services communicate critical weather information to the public quickly and effectively.

📱 Chromebook Ready: This system is optimized for Chromebook Linux environments. Clone the repo and run the live demo directly from your terminal with no internet required after setup!

Key Features

Real-Time Alert Generation

Create weather alerts instantly with customizable parameters including severity, urgency, and affected areas.

Multiple Event Types

Support for 8 different severe weather event codes including tornadoes, thunderstorms, floods, and more.

Geographic Targeting

Specify affected states and counties using FIPS codes for precise alert distribution.

JSON Export

Export alerts to JSON format for integration with other systems and long-term storage.

Alert Management

Track active alerts, cancel outdated warnings, and maintain alert history.

Offline Compatible

Works completely offline after initial setup. Perfect for field operations and remote areas.

🚀 Getting Started

For Chromebook Users:

  1. Enable Linux (Beta): Open Settings → Advanced → Developers → Linux development environment
  2. Open Terminal: Press Ctrl + Alt + T
  3. Clone Repository:
    git clone https://github.com/baxleychris9-spec/Eas-Weather-alert-for-USA.git
    cd Eas-Weather-alert-for-USA
  4. Install Dependencies:
    sudo apt update
    sudo apt install -y python3
  5. Run Live Demo:
    python3 live_demo.py
  6. Follow the Interactive Menu: Select options 1-11 to explore features

For All Users:

  1. Clone the Repository:
    git clone https://github.com/baxleychris9-spec/Eas-Weather-alert-for-USA.git
  2. Navigate to Project:
    cd Eas-Weather-alert-for-USA
  3. Ensure Python 3.7+ is Installed
  4. Run the Live Demo:
    python3 live_demo.py

Quick Test (Without Demo):

python3 src/alert_generator.py
